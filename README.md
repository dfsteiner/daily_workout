# daily_workout
20 minutes daily exercise to build a routine

A premium, high-visibility, zero-scroll mobile web application designed to track and guide you through a highly variable, 28-day functional fitness routine. Designed to be executed in exactly 20 minutes a day using mid-weight dumbbells, a kettlebell, or your own bodyweight.

Key Features

28-Day Optimized Split: Automatically rotates through Upper Body Strength, Lower Body Strength, Metabolic Conditioning (MetCon), Active Mobility, Push/Pull Strength, Athletic Power, and Restoration deep stretches.

Hands-Free Active HUD: The app automatically divides your 20-minute session into phases:

Dynamic Warm-Up (Minutes 0:00 - 2:00): Custom-tailored joint prep opens automatically.

Main Circuit (Minutes 2:00 - 18:00): Highlights the exact exercise, counts down work/rest intervals, and tracks your current sets in massive, high-contrast, color-coded digits.

Cool-Down (Minutes 18:00 - 20:00): Prompts restorative decompression to end the workout.

Double-Timer Displays: Features a massive interval timer readable from across the room alongside the overall session timer.

Interactive Set Trackers: Displays set completion markers ($S1 \rightarrow S4$) that update automatically based on the active timer on strength days, and are fully tappable on self-paced MetCon/Mobility days.

Local Progress Memory: Automatically tracks your daily completion state and counts your active habits streaks using localized browser memory.

Quick GitHub Pages Setup (View on your Phone!)

You can host this tracker entirely for free using GitHub Pages so you can launch it like a native app on your phone's home screen.

Create a new public repository on GitHub (e.g., 20-min-workout).

Clone or upload these project files into your repository:

├── index.html
├── assets/
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── app.js
└── README.md


Go to your repository's Settings tab on GitHub.

In the left-side menu, click Pages.

Under Build and deployment, select Deploy from a branch.

Set the branch to main (or master) and folder to / (root), then click Save.

In a minute, GitHub will give you a live URL (e.g., https://yourusername.github.io/20-min-workout/).

How to install as a Mobile App:

iPhone (Safari): Open your live GitHub Pages URL, tap the Share button, and select "Add to Home Screen".

Android (Chrome): Open your live URL, tap the Three Dots menu, and select "Add to Home screen".
